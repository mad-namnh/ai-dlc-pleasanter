# Architecture review findings (2026-11-04)

**Verdict:** Approved with conditions. The direction "configuration as code + two-way sync + round-trip" is right. A1–A3 and B1 must be addressed before touching a customer's production.

Each item is a backlog entry. Update *Status* and *Trace* as work progresses. **Trace** names the artefact that carries the finding: R = rule, lint or refusal in `pls`; T = regression test (`tools/pls/tests/`); K = knowledge-base entry (`skills/pls-kb-pleasanter/`); ADR; TD = line in `docs/tech-debt.md`. Every row has at least one, or says why none is needed (design review 2026-11-09, B9). Statuses and traces checked on 2026-11-12.

The ids of this register (A1…D33) are not the ids of the review criteria in `docs/review-criteria.md`; other documents cite them as **RF-A1** … **RF-D33**.
