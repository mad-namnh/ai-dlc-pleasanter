# Demo specification — equipment loans (備品貸出管理)

A request from a **fictional** customer (総務部), written by MADLAB for the framework demo. Paste the mail below into Claude Code as the specification. Only the Japanese text is the input; this header is for the presenter.

---

件名：備品貸出の管理をプリザンターでできないでしょうか

お疲れ様です。総務部です。

現在、ノートPC・モニター・プロジェクターなどの社内備品の貸出をExcelで管理していますが、
誰が何を借りているのか、いつ返ってくるのかが分からなくなることが多く困っています。
プリザンターで以下のような管理ができないでしょうか。

1. 備品の台帳を作りたい。管理番号（例：PC-001）、備品名、種別（ノートPC／モニター／プロジェクター／その他）、保管場所を登録します。
2. 貸出のたびに、どの備品を、誰が、いつからいつまで借りるかを総務が登録します。
3. 台帳を見れば、その備品が今貸出中かどうかが分かるようにしたい。
4. 返却されたら、総務がボタン一つで返却済みにできるようにしたい。返却日も残したいです。
5. 返却予定日を過ぎても返ってきていない貸出を一覧で確認したい。
6. 一般の社員には台帳だけ見せて、空いている備品を確認できるようにしたいです。社員が台帳や貸出を変更することはできないようにしてください。

できれば12月から使い始めたいです。よろしくお願いいたします。
