## Root cause (skill, not model)

Step 3 says "probe it on dev", and the checklist says "No reliance on unverified Pleasanter behaviour", but the skill does not say what to do when the probe **cannot be run before G2** (no environment in the eval; in real projects: no time, no test user). The agent did the reasonable thing the skill allowed: it kept the expected branch and attached a probe for later.

## Fix → skill 0.4

Add to step 3 and the G2 checklist:

> A probe whose result can **change the design** (add or remove an element, a requirement or a classification) is a **G2 prerequisite**. If it cannot be run before G2, design the branch that is **safe if the expectation is wrong** (e.g. restrict a process with access control instead of relying on read-only to hide its button) and present the probe as a confirmation, not as the decision. Never present only the expected branch.
