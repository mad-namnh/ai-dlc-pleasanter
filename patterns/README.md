# Patterns

Reusable solutions for **customer Pleasanter applications**. They are referenced by framework rules (e.g. ADR-0005) but are **not part of the framework core**.

| Pattern | Use when | Status |
|---|---|---|
| [ai-gateway](ai-gateway/) | A Pleasanter app calls an LLM (or any external API that needs a secret) | Deployed on MADLAB dev; parked |
